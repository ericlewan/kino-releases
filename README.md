# Kino

Kino for macOS: browse, stream and download movies and shows, and play them on your AirPlay TV.

## Install

1. Download the `.dmg` from the [latest release](https://github.com/ericlewan/kino-releases/releases/latest).
2. Open it and drag **Kino** into **Applications**.
3. The first time you open Kino, macOS may block it. Go to **System Settings → Privacy & Security**, scroll down and
   click **Open Anyway** next to Kino. You only need to do this once.

Needs macOS 14 or later.

## Updates

Kino checks for updates once a day and offers to install them. You can also check now from
**Kino → Check for Updates…**.
